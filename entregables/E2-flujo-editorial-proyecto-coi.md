## Componente 2: Manual de Operaciones COI con Claude

El Manual documenta como se usa Claude en la operativa editorial de COI:

### Proceso de produccion de articulos Insur-Insights con Claude

1. Abrir Proyecto COI Editorial
2. Aplicar brief con P05 (RTCFR)
3. Si hay documento de base: activar P02 (pre-intencion) + P11 (analisis documental)
4. Si se necesitan datos actuales: activar P12 (busqueda web)
5. Activar CoT con P06 para analisis complejo
6. Para el estilo editorial: few-shot con P07 si no esta en el Proyecto
7. Redactar con el Prompt Maestro P10
8. Revision final con P04

| Tarea | Sin Claude | Con Claude |

| Analisis de PDF largo | 2-3 horas | 30-40 minutos |
