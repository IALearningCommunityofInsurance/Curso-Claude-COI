Al finalizar la Semana 1 dispones de cinco plantillas que cubren las bases del uso profesional de Claude.

## Las cinco plantillas del bloque operativo

### P01 - Contexto COI
Establece la identidad institucional de COI cada vez que abres una conversacion nueva fuera del Proyecto.
**Uso:** Primera instruccion en cualquier conversacion editorial importante.

### P02 - Pre-intencion
Prepara a Claude antes de leer un documento largo. Define el filtro de atencion antes de la lectura.
**Uso:** Siempre antes de pegar un PDF o texto extenso.

### P03 - Anti-alucinacion
Activa el protocolo de verificacion de datos. Critico para cualquier trabajo con datos de mercado.
**Uso:** Anadir a cualquier prompt donde aparezcan datos numericos.

### P04 - Revision editorial
Evaluacion estructurada de cualquier texto en cinco dimensiones editoriales.
**Uso:** Antes de publicar cualquier articulo de Insur-Insights.

### P05 - RTCFR maestro
La plantilla base para construir cualquier prompt profesional.
**Uso:** Como punto de partida para cualquier tarea nueva.

## Validacion del entregable

Para confirmar que las plantillas estan operativas, ejecuta este test:

1. Abre una conversacion nueva en Claude.ai (fuera del Proyecto)
2. Pega P01 para establecer contexto
3. Elige una tarea editorial real
4. Construye el prompt con P05 (RTCFR)
5. Si necesitas datos, activa P03 al inicio
6. Al terminar, pasa el texto por P04

Si el flujo funciona de principio a fin, el Entregable S1 esta completo.
