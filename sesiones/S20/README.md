## Concepto central (15 minutos)

Veinte sesiones. Veinte plantillas. Cuatro entregables reales. Un sistema documentado.

Lo que tienes al final de este curso:

BIBLIOTECA DE PROMPTS (P01-P20):
- P01-P05: Operativos base (contexto, pre-intención, anti-alucinación, revisión, RTCFR)
- P06-P10: Técnicas avanzadas (CoT, Few-Shot, Proyecto, Formatos, Integrador)
- P11-P15: Producción (análisis documental, web, flujo editorial, informes)
- P16-P20: Automatización (encadenamiento, ponencias, gestión del conocimiento, meta-prompt, sistema)

LOS 4 ENTREGABLES:
- E1: Biblioteca P01-P05 operativa
- E2: Flujo editorial + Proyecto COI configurado
- E3: Informe de mercado publicable bajo marca COI
- E4: Sistema Personal COI V1.0 (este documento)

EL SISTEMA PERSONAL V1.0 incluye:
1. Las 20 plantillas organizadas por caso de uso
2. El Proyecto COI Editorial configurado en Claude.ai
3. El flujo de trabajo semanal documentado
4. El manifiesto de lo aprendido
5. La plantilla de revisión anual (para dentro de 12 meses)

El Nivel 2 empieza aquí.

## Practica (30 minutos)

Sesion de cierre: El sistema documentado

PASO 1 - MAPA DEL SISTEMA:
"Ayúdame a documentar mi Sistema Personal COI V1.0.
Tengo 20 plantillas (P01-P20). Para cada bloque de 5, escribe:
- El nombre del bloque
- El patrón de uso (cuándo usar estas plantillas juntas)
- El caso de uso más frecuente en COI
- El resultado tipo que produce"

PASO 2 - FLUJO SEMANAL:
"Diseña el flujo de trabajo semanal ideal para un editor de Insur-Insights 
que usa estas 20 plantillas. Estructura por día (lunes-viernes) con:
- Tarea editorial habitual de ese día
- Qué plantillas activa
- Output esperado"

PASO 3 - MANIFIESTO DE CIERRE:
"Escribe el Manifiesto de cierre del curso: 10 principios del uso profesional 
de Claude para trabajo editorial e intelectual, extraídos de lo que hemos 
aprendido en estas 20 sesiones. Estilo directo, sin jerga corporativa."

PASO 4 - REVISION ANUAL:
"Crea una plantilla de Revisión Anual para que, dentro de 12 meses, 
pueda evaluar si sigo usando el sistema correctamente y qué ha cambiado.
Incluye: preguntas de autoevaluación + métricas de uso + criterios de actualización."


---

## Reflexion (10 minutos)

Antes de guardar la plantilla, responde:
- Que parte de esta sesion cambio como usas Claude?
- En que tarea real de COI aplicaras esto esta semana?
- Que variante del prompt quieres probar en la proxima sesion?
