**Fecha:** Lunes 25 agosto 2025 - CIERRE SEMANA 3  
**Semana:** 3 - Produccion real  
**Plantilla resultante:** ```
INFORME DE MERCADO COI - PLANTILLA MAESTRA (P15)

BRIEF:
Informe [tipo] sobre [tema] / Periodo: [fechas] / Tesis: [en una frase]
Audiencia: directivos sector asegurador iberoamericano / Extension: 1.500-2.000 palabras

ARQUITECTURA (aprobar antes de desarrollar):
- Titulo del informe
- Subtitulo editorial
- Seccion 1: [Contexto y situacion actual]
- Seccion 2: [Analisis de tendencias]
- Seccion 3: [Perspectiva y retos]
- Tabla: [indicadores clave con fuentes]
- Conclusion: implicaciones para el sector

PROCESO:
1. Aprobar arquitectura
2. Adjuntar/buscar datos por seccion
3. Desarrollar cada seccion con P14

METADATA FINAL:

Descripcion (150 caracteres)
Etiquetas: [3-5 terminos clave]

```  
**Duracion:** 60 minutos

---

## Concepto central (15 minutos)

Esta sesion es el cierre de la Semana 3. El objetivo es producir el Entregable S3:
un informe de mercado de tres secciones, publicable bajo marca COI.

**Lo que integra esta sesion:**
- Analisis documental (S11)
- Busqueda web si es necesario (S12)
- Flujo editorial 6 fases (S13)
- Tecnica de dos prompts para informes (S14)
- Todo el framework RTCFR y tecnicas de S1-S2

**El Entregable S3 es:**
- Un informe de 1.500-2.000 palabras
- Tres secciones analiticas
- Al menos una tabla de datos
- Perspectiva editorial COI propia
- Listo para publicar en COI Magazine o como informe standalone

Al terminar esta sesion: 15 plantillas acumuladas (P01-P15).

---

## Practica (30 minutos)

**Produccion del Entregable S3**

Elige un tema de mercado relevante para COI (ejemplos: concentracion del mercado corredor, 
bancaseguros en LATAM, digitalizacion de ramos, resultados tecnicos no vida).

Ejecuta el flujo completo:

```
PASO 1 - BRIEF DEL INFORME:
"Vamos a producir el Informe de Mercado COI de [mes/trimestre] sobre [TEMA].
Audiencia: directivos del sector asegurador iberoamericano
Tesis: [tu tesis]
Estructura objetivo: 3 secciones + tabla + conclusion
Extensión: 1.500-2.000 palabras"

PASO 2 - ARQUITECTURA (P14):
[Aplicar el Prompt 1 de P14]

PASO 3 - INVESTIGACION:
[P11 con documentos adjuntos + P12 con busqueda web si aplica]

PASO 4 - DESARROLLO SECCIONES:
[Una por una con P14, Prompt 2]

PASO 5 - REVISION GLOBAL:
"Revisa el informe completo:
¿Hay coherencia entre las tres secciones?
¿La conclusion se desprende del analisis?
¿Algun dato necesita verificacion adicional?
Lista los 5 cambios prioritarios."

PASO 6 - VERSION FINAL:
"Entrega la version final lista para publicar bajo marca COI.
Incluye: portada conceptual (titulo + subtitulo + fecha), 
las tres secciones, tabla de datos, conclusiones."
```
