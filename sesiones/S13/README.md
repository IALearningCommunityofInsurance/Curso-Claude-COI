# Sesion 13 - Flujo editorial completo: de dato a articulo publicable en una sesion

**Fecha:** Jueves 21 agosto 2025  
**Semana:** 3 - Produccion real  
**Plantilla resultante:** ```
FLUJO EDITORIAL 6 FASES COI (P13)
Tiempo total estimado: 50-60 minutos

F1-BRIEF:
Articulo para [publicacion] / Tema: [X] / Tesis: [Y] / Palabras: [N] / Restriccion: [Z]

F2-INVESTIGACION:
[Busqueda web O adjuntar documento]
Dame: 5 datos relevantes para la tesis + 1 contraargumento posible

F3-ESTRUCTURA:
Con el brief y datos: propón titular + subtitulo + 3 secciones (solo titulos + idea central)

F4-BORRADOR:
Escribe el articulo completo siguiendo la estructura aprobada. Estilo COI. Sin cliches.

F5-REVISION:
Evalua con P04: ¿tesis clara? ¿datos apoyados? ¿titular cumple? -> 3 cambios prioritarios

F6-FORMATO-FINAL:
Aplica cambios + version lista para publicar + metadata (titulo SEO, descripcion, etiquetas)
```  
**Duracion:** 60 minutos

---

## Concepto central (15 minutos)

El flujo editorial de 6 fases integra todo lo aprendido en un proceso reproducible:

```
Fase 1: BRIEF        (5 min)  - Que vamos a escribir y para que
Fase 2: INVESTIGACION (10 min) - Datos e informacion base
Fase 3: ESTRUCTURA   (5 min)  - El esqueleto del articulo
Fase 4: BORRADOR     (15 min) - La escritura con Claude
Fase 5: REVISION     (10 min) - Mejora editorial
Fase 6: FORMATO      (5 min)  - Preparacion para publicacion
```

**La clave del flujo:** Cada fase tiene un output concreto que es el input de la siguiente.
No es un proceso lineal rigido: puedes volver a la fase anterior, pero siempre sabiendo donde estas.

**Por que 6 fases y no un solo prompt:**
Un solo prompt pide demasiado. Claude puede hacer el articulo de golpe, pero el resultado es generico.
El flujo produce articulos con perspectiva editorial real porque el razonamiento esta distribuido.

---

## Practica (30 minutos)

**Ejercicio: El flujo completo en 60 minutos**

Elige un tema de actualidad aseguradora y ejecuta las 6 fases:

```
FASE 1 - BRIEF (5 min):
"Vamos a escribir un articulo para Insur-Insights sobre [TEMA].
Tesis propuesta: [TU TESIS]
Lector: directivo de correduria española
Longitud: 700 palabras
Restriccion especial: [la que aplique]
Confirma que has entendido el brief."

FASE 2 - INVESTIGACION (10 min):
[Con busqueda web o con documento adjunto]
"Busca/Analiza la informacion disponible sobre este tema.
Dame: los 5 datos mas relevantes para la tesis + 1 contraargumento."

FASE 3 - ESTRUCTURA (5 min):
"Con el brief y los datos, propón la estructura del articulo:
Titular + subtitulo + 3 secciones con sus ideas principales.
No escribas el texto aun; solo la arquitectura."

FASE 4 - BORRADOR (15 min):
"Ahora escribe el articulo completo siguiendo la estructura aprobada.
Aplica el estilo editorial COI: tesis clara, datos verificados, sin cliches."

FASE 5 - REVISION (10 min):
"Revisa el borrador con el criterio de P04: 
¿La tesis esta clara desde el inicio?
¿Los datos apoyan el argumento?
¿El titular cumple lo que promete?
Propón los 3 cambios prioritarios."

FASE 6 - FORMATO (5 min):
"Aplica los cambios de revision y entrega la version final en formato 
listo para publicar en Insur-Insights. Incluye nota de metadata: 
titulo SEO, descripcion (150 caracteres) y etiquetas sugeridas."
```
