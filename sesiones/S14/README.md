# Sesion 14 - Informes estructurados: arquitectura, jerarquia y analisis de mercado

**Fecha:** Viernes 22 agosto 2025  
**Semana:** 3 - Produccion real  
**Plantilla resultante:** ```
INFORME ESTRUCTURADO COI (P14)

== PROMPT 1: ARQUITECTURA ==
Diseña la estructura de un informe de [tipo] sobre [tema] para COI.

Debe incluir:
- Titulo del informe
- Subtitulo editorial (la tesis en una frase)
- Seccion 1: [tipo de contenido esperado]
- Seccion 2: [tipo de contenido esperado]
- Seccion 3: [tipo de contenido esperado]
- Tabla de datos: especifica los [N] indicadores que incluiria
- Conclusion y perspectivas

No escribas el contenido. Solo la arquitectura y para cada seccion: 
titulo + subtitulo + tipo de datos necesarios.

== PROMPT 2: DESARROLLO ==
[Una vez aprobada la arquitectura]
Desarrolla la [seccion N] del informe.
Titulo: [aprobado]
Datos disponibles: [adjuntos o especificados]
Extension: [N] palabras
Estilo COI: analitico, perspectiva propia, datos con fuente
```  
**Duracion:** 60 minutos

---

## Concepto central (15 minutos)

Un informe de mercado COI no es un articulo largo: es una estructura diferente,
con jerarquia de informacion, tabla de datos y secciones analiticas definidas.

**La tecnica de los dos prompts:**

Prompt 1 - ARQUITECTURA:
```
Diseña la estructura de un informe de mercado sobre [tema].
No escribas el contenido. Solo dame:
- Titulo del informe
- Las 3-4 secciones principales con sus subtitulos
- El tipo de datos que necesita cada seccion
- La tesis editorial del informe en una frase
```

Prompt 2 - DESARROLLO:
```
Ahora desarrolla la seccion [X] con esta estructura aprobada.
Datos disponibles: [adjuntar o especificar]
Extension: [N] palabras.
```

**Por que funciona mejor que un solo prompt:**
- Puedes aprobar o modificar la arquitectura antes de escribir
- Cada seccion se desarrolla con el contexto completo
- El informe final tiene coherencia estructural real

**Los 4 tipos de informe COI:**
1. Informe de mercado anual (panorama + estadisticas + perspectivas)
2. Informe de coyuntura (trimestral, indicadores clave)
3. Estudio de segmento (correduria, bancaseguros, digital)
4. Nota de analisis rapido (2-3 paginas, evento especifico)

## Practica (30 minutos)

**Ejercicio: Informe en dos prompts**

```
PROMPT 1 - ARQUITECTURA:
"Diseña la estructura de un informe COI sobre [TEMA].

Requisitos:
- 3 secciones analiticas principales
- Una seccion de tabla de datos (especifica que datos irían)
- Una seccion de conclusiones y perspectivas
- Tesis editorial del informe en una frase

Solo la estructura; no desarrolles el contenido aun."

---

[Tras aprobar la estructura:]

PROMPT 2 - DESARROLLO SECCION 1:
"Desarrolla la Seccion 1 del informe con esta estructura aprobada.
Titulo de la seccion: [el que hayas aprobado]
Datos disponibles: [los que tengas]
Extension: 400 palabras
Estilo: analitico con tesis, sin cliches, datos verificados"

---

PROMPT 3 - DESARROLLO SECCION 2:
[Igual, seccion por seccion]
```
