# Sesion 12 - Busqueda web integrada: datos actuales, fuentes verificables, tiempo real

**Fecha:** Miercoles 20 agosto 2025  
**Semana:** 3 - Produccion real  
**Plantilla resultante:** ```
PROTOCOLO BUSQUEDA WEB COI (P12)
[Requiere busqueda web activada en Claude.ai]

INSTRUCCION DE BUSQUEDA:
Necesito informacion actualizada sobre [tema] para un articulo de Insur-Insights.

Criterios de busqueda:
- Periodo: [ultimos 30 dias / 3 meses / 2025]
- Geografía: [España / mercado iberoamericano / global]
- Tipo de fuente preferida: primaria (reguladores, compañias, organismos sectoriales)
- Excluir: opinion sin datos, repeticion de notas de prensa

Para cada resultado encontrado, proporciona:
1. Titular
2. Fuente y tipo (primaria/secundaria)
3. Fecha de publicacion
4. URL
5. Dato clave en una frase

VERIFICACION ANTES DE USAR:
Antes de incluir cualquier dato en el articulo, indica:
- Si puedes confirmar la URL es accesible
- Si el dato viene de una fuente primaria o secundaria
- Si hay datos contradictorios sobre el mismo tema
```  
**Duracion:** 60 minutos

---

## Concepto central (15 minutos)

Claude puede buscar en Internet cuando la busqueda web esta activada (icono en Claude.ai).
Esto cambia radicalmente lo que puede hacer: acceso a noticias recientes, datos de 2025, normativa vigente.

**Cuando USAR la busqueda web:**
- Noticias del sector de las ultimas semanas
- Datos de mercado recientes (primas, resultados, regulacion)
- Verificar si una compañia ha cambiado estructura/liderazgo
- Buscar que se ha publicado sobre un tema antes de escribir

**Cuando NO usar la busqueda web:**
- Analisis que ya tienes el material (mas ruido que señal)
- Cuando necesitas control total de las fuentes
- Para redaccion creativa donde los datos son secundarios

**El protocolo de verificacion antes de publicar:**
1. Pide siempre la URL de la fuente
2. Verifica que la fuente sea primaria (no agregador)
3. Comprueba la fecha del dato
4. Para datos numericos: confirma en la fuente original antes de publicar

---

## Practica (30 minutos)

**Ejercicio: La busqueda verificada**

Con la busqueda web activada en Claude:

```
PASO 1 - BUSQUEDA DIRIGIDA:
"Busca las ultimas noticias relevantes sobre [tema] en el mercado 
asegurador iberoamericano publicadas en los ultimos 30 dias.
Para cada resultado, dame: fuente, fecha, titular y URL."

PASO 2 - VERIFICACION:
"De esas noticias, cual tiene la fuente mas fiable y el dato mas verificable?
Distingue entre fuentes primarias (ICEA, DGS, compañias) y secundarias (prensa)."

PASO 3 - APLICACION EDITORIAL:
"Con los datos verificados que encontraste, escribe un parrafo de apertura 
para un articulo de Insur-Insights. Indica entre parentesis la fuente de 
cada dato que uses."
```
