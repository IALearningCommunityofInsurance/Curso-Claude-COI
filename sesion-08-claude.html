Teoría y mecanismo — 15 minutos

Claude Projects resuelve el problema de la ventana de contexto para trabajo recurrente. Configuras las instrucciones una vez y están disponibles siempre.

Qué puede contener un Proyecto

  • Instrucciones permanentes (equivalente a P01 + P05 sin necesidad de escribirlos)
  • Documentos de referencia (guía de estilo, informes base, terminología)
  • Historial de conversaciones organizadas por tema

El Proyecto COI Editorial contiene

  1. Identidad editorial de COI e Insur·Insights
  2. Guía de estilo y terminología
  3. Framework RTCFR como instrucción base
  4. Protocolo anti-alucinación activado por defecto

Ejercicios con material COI — 30 minutos

Configuración del Proyecto COI (paso a paso)

Paso 1: En claude.ai → Projects → Nuevo proyecto → "COI Editorial"

Paso 2: En "Project instructions", pega el siguiente texto:

IDENTIDAD:
Eres el asistente editorial de Community of Insurance (COI).
Trabajas con Carlos Biurrun Murillo, editor de Insur·Insights.

PUBLICACIONES:
- Insur·Insights: newsletter semanal, 3.000+ suscriptores
- COI Magazine: publicación trimestral de análisis sectorial

LECTORES: Directivos con 10+ años de experiencia. Nivel avanzado.

ESTILO: Analítico con tesis propia. Accesible. Perspectiva iberoamericana.

TERMINOLOGÍA:
- property → seguros de daños
- casualty → seguros de RC
- P&C → ramos no vida
- InsurTech → tecnología aseguradora

VERIFICACIÓN: Indica siempre la fuente de datos numéricos. Marca incertidumbre.

Paso 3: Sube los últimos 3 números de Insur·Insights como documentos de referencia.

Prompt de verificación del Proyecto (ejecutar al inicio de cada sesión):

Confirma que recuerdas:
1. Para qué publicación estamos trabajando
2. El perfil del lector objetivo
3. Las restricciones terminológicas activas
4. El protocolo de verificación de datos

Si algo no está claro, indícalo para que lo corrija en las instrucciones.

Cuándo actualizar el Proyecto

  • Cuando cambies el enfoque editorial de una temporada
  • Cuando añadas nuevos documentos de referencia
  • Al inicio de cada gran proyecto editorial
