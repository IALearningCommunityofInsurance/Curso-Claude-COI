## Prompt

```
SELECTOR DE FORMATO:

OPCION A - Articulo Insur-Insights:
"Formato: Titular (12 palabras max) + subtitulo + 3 secciones con intertitulos +
conclusion. Extension: 700-900 palabras."

OPCION B - Resumen ejecutivo:
"Formato: 3 parrafos: situacion / analisis / implicacion practica.
Maximo 200 palabras. Sin intertitulos."

OPCION C - Tabla de analisis:
"Formato: tabla con [variable en filas] y [perspectivas/dimensiones en columnas].
Incluye una fila de valoracion 1-5 al final."

OPCION D - Post LinkedIn:
"Formato: Hook (2 lineas) + 4 parrafos de 50-70 palabras +
cierre con pregunta + 3 hashtags. Total: 250-300 palabras."

OPCION E - Newsletter breve:
"Formato: titulo de seccion + parrafo introductorio (40 palabras) +
3 puntos destacados (40 palabras cada uno) + llamada a la accion (20 palabras)."

OPCION F - Guion de ponencia:
"Formato: estructura de [N] bloques tematicos con titulo, idea central,
ejemplo y transicion para cada bloque. Estimacion de tiempo por bloque." 
```
