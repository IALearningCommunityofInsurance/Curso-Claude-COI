Concepto central
Teoría y mecanismo — 15 minutos

El meta-prompt es la habilidad de usar Claude para generar el prompt correcto para una tarea nueva. En lugar de construir el RTCFR desde cero, le preguntas a Claude cómo preguntarle a Claude.

El marco de tres preguntas para cualquier tarea nueva

  1. ¿Qué quiero conseguir exactamente? → Tarea
  2. ¿Qué necesita saber Claude para hacerlo bien? → Rol + Contexto
  3. ¿Cómo quiero que estructure la salida? → Formato + Restricciones

Cinco casos de uso nuevos para COI

  1. Análisis de competencia editorial
  2. Evaluación de propuestas de colaboración
  3. Preparación de entrevistas con directivos
  4. Análisis de feedback de lectores
  5. Planificación de la agenda editorial trimestral

La meta-habilidad: Una vez que sabes construir un prompt RTCFR para cualquier tarea, no necesitas más plantillas: puedes generar las tuyas.

Práctica real
Ejercicios con material COI — 30 minutos

El meta-prompt en acción

PASO 1 - DISEÑO DEL PROMPT:
"Necesito hacer lo siguiente con Claude: [describe la tarea en lenguaje natural].
No lo hagas aún. Primero diseña el prompt RTCFR óptimo para esta tarea.
El prompt debe incluir: rol apropiado, tarea clara, contexto necesario,
formato del output y las 2-3 restricciones más importantes."

PASO 2 - AJUSTE:
"El prompt propuesto es bueno pero quiero que ajustes:
- El rol: más específico en [aspecto]
- Añade también esta restricción: [restricción adicional]"

PASO 3 - EJECUCIÓN:
"Bien, ahora aplica ese prompt para realizar la tarea con esta información: [datos]"

PASO 4 - META-APRENDIZAJE:
"¿Qué hizo este prompt que lo hace más efectivo que uno básico?
Identifica los 2-3 elementos que más impacto tuvieron en el resultado."
