## ¿Qué es este curso?

Un programa de autoaprendizaje intensivo diseñado para dominar Claude como herramienta editorial y analítica aplicada al sector asegurador iberoamericano. No es un curso genérico de IA: cada sesión produce un resultado directamente aplicable a la operativa de COI / CICA / Insur·Insights.

**Filosofía:** *Método Progresivo* — cada semana termina con un entregable real, no un ejercicio hipotético.

## Estructura de cada sesión (60 minutos)

```
15' — CONCEPTO        Teoría y mecanismo explicado con precisión
30' — PRÁCTICA REAL   Ejercicio con material real de COI/CICA
10' — REFLEXIÓN       Técnica avanzada derivada del concepto
 5' — PLANTILLA       Prompt final que se incorpora a la Biblioteca COI
```

## Framework central: RTCFR

El método que estructura todos los prompts del curso:

| Componente | Qué define | Ejemplo COI |
|-----------|-----------|-------------|
| **R** — Rol | Quién es Claude en esta tarea | "Eres analista editorial especializado en seguros iberoamericanos" |
| **T** — Tarea | Qué tiene que hacer exactamente | "Redacta un artículo de análisis de 800 palabras" |
| **C** — Contexto | Información de fondo relevante | "El lector es directivo de correduría, nivel avanzado" |
| **F** — Formato | Cómo debe estructurarse la salida | "Titular + subtítulo + 3 secciones + conclusión" |
| **R** — Restricción | Qué no debe hacer o límites concretos | "No uses jerga anglosajona. Fuentes solo verificadas." |

## Cómo usar este repositorio

1. **Abre** `itinerario-curso-claude-agosto.html` en tu navegador para la vista visual completa
2. **Navega** a `sesiones/S01-que-es-claude/` y empieza por `README.md`
3. **Sigue** el orden S01 → S20 o salta a la semana que necesitas
4. **Acumula** las plantillas en `prompts/biblioteca/` — ese es tu activo real al terminar
5. **Produce** los 4 entregables de `entregables/` — son los hitos de evaluación
